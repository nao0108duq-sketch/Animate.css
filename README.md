## Prueba de Animate.css
Ejercicio sencillo para probar la biblioteca Animate.css en una página HTML.

Se usan tres animaciones:
- animate__bounce: hace rebotar el título.
- animate__fadeInLeft: hace aparecer el primer botón desde la izquierda.
- animate__shakeX: mueve el segundo botón de lado a lado.
Para usar Animate.css, combina la clase animate__animated con la clase del efecto que quieras aplicar.

Documentación: https://animate.style/
